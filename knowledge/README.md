# knowledge/ — the published process records (publish-on-cite)

This tree exists because two independent external reviewers, in the same round, found that the
shipped corpus cites `knowledge/` process records that did not resolve publicly (66 citations to
36 paths at the time of measurement). The governing principle, adopted 2026-08-24 on the
coordinator's ruling: **publish-on-cite** — any `knowledge/` path cited as the basis of a status
in a public-facing artifact qualifies for this mirror, with its quarantine markers preserved.
Citation is the curation trigger; the tree is therefore partial by design and grows as citations
do.

**What a reader must know before using anything here:**

- **These are working records, not results.** Banked results live in the engine
  (`twt_core.py` / `twt_candidate_v3.py`, suite-checked) and the papers. A statement in an audit
  record, probe script, review verdict, or candidate note carries only the tier its own text
  assigns it — CANDIDATE/FRAMING material is speculation-grade by the project's own rules, and
  quarantine/fence markers in these files are load-bearing, not decoration.
- **Probe scripts ship with banked-status: none** unless their record says otherwise. The
  `candidates/probes_2026-07-29/` scripts are the §C.4.5 closure computations, published so the
  "computed rather than waved at" claim is auditable; their enumerations (including the monomial
  list) are generated by running them.
- **Review records** (`reviews/`, `audit/external_review_*`) include adverse findings, refuted
  drafts, and overturned claims — deliberately: the process's value is that its failures are on
  the record. Quoting a superseded draft as the project's position is a misuse this README is
  the fence against; each record's own header states its status.

Currently published on this principle: the round-4 external-review record set
(`audit/external_review_r4_2026-08-24/`, incl. the four primary-read dossiers), the OI-1
adjudication (`audit/oi1_anomaly_ledger_2026-08-24/`), the Golterman–Shamir applicability
adjudication (`audit/gs_nogo_adjudication_2026-08-24/`), the su(2)-menu clean-room rederivation
(`audit/consolidation_2026-08-21/REDERIVATION_SU2_MENU_2026-08-21.md`), the §C.4.5 probe scripts
(`candidates/probes_2026-07-29/`), and one full commission exemplar — submission plus

being assembled and lands with a subsequent sync.
